Deployment documentation

The former interactive guide is archived because its deployment, migration, and upload instructions are obsolete. This development-only page is a documentation index, not an alternative deployment procedure.

  • AGENTS.md — repository and production-safety rules.
  • docs/DEPLOYMENT.md — authoritative release and migration runbook.
  • docs/CLOUDFLARE_SETUP.md — infrastructure configuration.
  • docs/PRODUCTION_OPERATIONS.md — operational verification.

Read these files in the current checkout. Production releases require checks for the exact commit and environment approval; schema verification must report EXACT before deployment. Do not use a local deploy command to bypass those gates.
